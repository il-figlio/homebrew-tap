# il-figlio/tap

Homebrew casks for il-figlio's macOS apps.

```sh
brew install --cask il-figlio/tap/headroom
```

| Cask | App |
| --- | --- |
| `headroom` | [Headroom](https://github.com/il-figlio/headroom): memory pressure, disk space, and per-app memory from the notch or menu bar |

Casks are rendered from each app's release by its own release tooling.
